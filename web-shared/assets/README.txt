Drop the official City of Caloocan seal here as:  caloocan-seal.png
(a square or round PNG, at least 256x256 pixels, transparent or white background).

Then run:  cd firebase  &&  npm run deploy:web
The build copies it to the landing page and to the login, admin, staff and resident sites.
Until this file exists, the sites show a navy square with an orange ring and "LCS".
